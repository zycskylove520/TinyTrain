# 学习如何构建模型

在 tinytrain 框架中，我们提供两种模型构建方式：

### 🛠️ 方式一：配置文件驱动（推荐）

使用灵活的配置文件构建可动态伸缩的模块化模型，便于扩展和维护。

**开始学习**：[学习创建自定义AI模块](01-create-module.md)

### ⚡ 方式二：原生 PyTorch 方式

直接使用熟悉的 PyTorch API 构建模型，适合习惯原生开发流程的用户。

**开始学习**：[构建基于Pytorch的原生模型](03-build-easy-model.md)

---

### 选择建议

* 新手或团队项目：推荐使用配置文件方式，结构清晰且易于维护
* PyTorch 熟练用户：可选择原生方式快速迁移现有代码
* 实验和研究：配置文件方式便于参数调整和实验管理
